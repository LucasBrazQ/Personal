Como instalar

  • Gmail: Configurações → Ver todas as configurações → Assinatura → Criar nova → cole (Ctrl+V) a assinatura copiada.
  • Outlook (web): Configurações → E-mail → Redigir e responder → Assinatura de e-mail → cole.
  • Outlook (desktop): Arquivo → Opções → E-mail → Assinaturas → Novo → cole.
  • Apple Mail: Mail → Ajustes → Assinaturas → "+" → cole.

Dica: a foto precisa estar hospedada em uma URL pública (ex.: LinkedIn, Google Drive com link direto, ou seu site) para aparecer para os destinatários.
